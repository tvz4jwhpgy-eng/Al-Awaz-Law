# Al-Awaz-Law
قانون العواز (Al-Awaz Law)
المُبتكر (Creator): يوسف (Yusuf)
التاريخ (Date): 31 مايو 2026
[العربية]
قانون العواز هو قانون فيزيائي مبتكر لتحديد استقرار المدارات الكونية بناءً على التوازن بين "قوة الشد" والوزن الذاتي للأجرام السماوية.
المعادلات الرياضية:
1 قانون العواز الأول: T = \frac{W_{Total}}{R}
2 قانون العواز الثاني: D = T - W_{small}
معيار النتائج:
 إذا كان D < 0: الجرم يبتعد.
 إذا كان D > 0: الجرم يقترب.
 إذا كان D = 0: استقرار مداري تام.
[English]
The Al-Awaz Law is a new physical law designed to determine the orbital stability of celestial bodies based on the balance between "Tensile Force" and the object's own weight.
Mathematical Equations:
1 The First Al-Awaz Law: T = \frac{W_{Total}}{R}
2 The Second Al-Awaz Law: D = T - W_{small}
Result Criteria:
 If D < 0: The object moves away.
 If D > 0: The object moves closer.
 If D = 0: Perfect orbital stability.
